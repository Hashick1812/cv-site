# cv-site

Персональный CV-сайт Ислама Куттыбаева (Data Scientist, ТОО «Adam Labs») в стиле «Звёздных войн».

Сайт — статический: `index.html` (разметка на русском, стили и скрипты) и `i18n.js` (переводы на казахский и английский). Без сборки и зависимостей, кроме шрифтов Google Fonts.

## Что внутри

- **Вступительная заставка** — «Не так давно, в галактике…», логотип и бегущий текст-crawl. Показывается один раз за сессию, пропускается кликом, `Esc` или `Enter`; повтор — кнопка «▶ Интро» в меню.
- **Музыка в заставке** — оригинальная оркестровая тема, синтезируется в браузере (Web Audio), включается кнопкой «Включить звук» (браузеры не дают играть звук без клика). Выбор запоминается.
- **Три языка** — ҚАЗ / РУС / ENG в шапке сайта. Язык выбирается автоматически по браузеру, выбор запоминается.
- **Разделы:** Личное дело · Текущая миссия (Adam Labs) · Хроника опыта · Карьерный маршрут · Кодекс джедая данных · Арсенал навыков · Сертификаты · Образование и языки · Контакты.
- **Сохранить PDF** — кнопка в первом экране открывает печать; для печати есть отдельная светлая компактная вёрстка (~4 страницы A4).
- Адаптив под телефоны, поддержка `prefers-reduced-motion`.

## Полезно знать

- Ссылка без заставки (например, для рекрутеров): `index.html?nointro`.
- Ссылка на конкретном языке: `?lang=en`, `?lang=kk`, `?lang=ru` (можно вместе: `?lang=en&nointro`).
- **Как менять тексты:** русский текст — в `index.html`, переводы — в `i18n.js`, где ключ — это русский текст. Меняете фразу в `index.html` — поменяйте её и как ключ в `i18n.js`, иначе на других языках останется старый перевод.
- **Свой трек для заставки** (только с лицензией на использование): положите файл рядом с `index.html` и укажите путь в `INTRO_TRACK` в `index.html`.
- Контент правится прямо в `index.html` — каждый раздел помечен комментарием (`<!-- 02 Текущая миссия -->` и т.д.).
