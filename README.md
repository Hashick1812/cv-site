# cv-site

Персональный CV-сайт Ислама Куттыбаева (Data Scientist, ТОО «Adam Labs») в стиле «Звёздных войн».

Весь сайт — один файл `index.html` без сборки и зависимостей (кроме шрифтов Google Fonts).

## Что внутри

- **Вступительная заставка** — «Не так давно, в галактике…», логотип и бегущий текст-crawl. Показывается один раз за сессию, пропускается кликом, `Esc` или `Enter`; повтор — кнопка «▶ Интро» в меню.
- **Разделы:** Личное дело · Текущая миссия (Adam Labs) · Хроника опыта · Карьерный маршрут · Кодекс джедая данных · Арсенал навыков · Сертификаты · Образование и языки · Контакты.
- **Сохранить PDF** — кнопка в первом экране открывает печать; для печати есть отдельная светлая компактная вёрстка (~4 страницы A4).
- Адаптив под телефоны, поддержка `prefers-reduced-motion`.

## Полезно знать

- Ссылка без заставки (например, для рекрутеров): `index.html?nointro`.
- Контент правится прямо в `index.html` — каждый раздел помечен комментарием (`<!-- 02 Текущая миссия -->` и т.д.).
